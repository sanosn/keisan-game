# けいさんパチパチ

小学生（入学前〜）むけの けいさんゲーム。タブレットのホーム画面に追加して、アプリとして遊べます。

## ファイル
- `index.html` / `style.css` / `game.js` … ゲーム本体（レベルは `game.js` の `LEVELS` に追加）
- `manifest.webmanifest` … アプリ名・アイコン・全画面表示の設定
- `sw.js` … オフラインで遊ぶための仕組み
- `icons/` … アプリアイコン（`icon.svg` が元絵）

## 更新するとき
ゲームを直したら、`sw.js` の `VERSION`（例：`'v1'` → `'v2'`）を1つ上げてから公開してください。
タブレット側では、次にアプリを開いたときに裏で新しい版を受け取り、その次の起動から新しい版になります。
